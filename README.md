# Just Due
Stay organized. Never miss a deadline.

# Project Description
Just Due is a student task and deadline tracker designed to help students organize their schoolwork. It allows students to add, view, edit, and delete tasks while keeping track of their completion status. The application will use JSON files to save task information so that users can access their saved tasks even after closing the program.

# Features
Add Task – Allows users to add a new assignment or school activity.\
View Tasks – Displays all saved tasks and their details.\
Edit Task – Allows users to update task information, such as the task name or deadline.\
Delete Task – Removes tasks that are no longer needed.\
Mark as Completed – Changes the status of a task once it has been finished.\
View Upcoming Deadlines – Shows tasks with approaching deadlines.\
Task Summary – Displays the number of pending, completed, and overdue tasks.\

# Project Purpose
This purpose of this project is to help students organize their schoolwork by keeping track of their assignments, activities, and deadlines. Just Due aims to prevent missed submissions, reduce cramming, and help students manage their time more effectively.
